# Cycle pet

The Today companion pet is intentionally supportive rather than diagnostic.

- Cycle phase supplies only a broad baseline demeanor.
- Fresh logs can override that baseline.
- Rough symptoms make the pet stay close; it should not mimic pain or look ill.
- Positive logs are allowed to look playful in any phase.
- Tap is a short acknowledgement/nod.
- Horizontal strokes pet the companion while leaving vertical scrolling free.
- Idle motion is event-based rather than a permanent animation loop.
- Autonomous motion is disabled when reduced-motion is enabled.
- Timers stop when the app leaves the foreground.
